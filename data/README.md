# data/ - input data and model files

| Path | Contents |
|---|---|
| `starter_pack/` | Template CSVs for assets, vulnerabilities, financial impact and remediation actions. |
| `demo_synthetic_asset_findings.csv` | Example asset findings (synthetic) for the demo. |
| `models/` | Model reports and the trained model (created on first run; not stored in git). |
| `raw/` | Put the NVD `nvdcve-2.0-*.json.zip` here to import CVEs (not stored in git). |
